# PowerPoint preview validation

Recorded 2026-09-30. These checks cover the sampled sources and the stated platform; they do not establish fidelity for every design or PowerPoint version.

- Development checks: 18 tests passed with `node --test source/tests/fidelity.test.js source/tests/powerpoint.test.js` on macOS. Fixtures cover source dimensions, editable gradients/shadows, exact paths, font/style reporting, paragraph offsets, media effects, structural validation and stale-render rejection. The default Keynote writer profile remains covered.
- Both Codex and Claude Code ran the installed Google Slides → PowerPoint and Figma → PowerPoint skills against local copies of the actual pilot extracts. Both produced structurally valid ten-slide and five-slide packages, retained source order and aspect ratio, and reported their outputs as native rendering unverified. Assistant CLI checks alone are not visual evidence.
- Both assistants also ran offline compatibility pilots for the three existing converters. Their readers, default Keynote intermediate writers and local Figma script generation completed in source order. This does not requalify their native fidelity. The Keynote profile does not implement the PowerPoint-specific image filters/blur used in reconstruction candidates. Google → Figma still reduces mixed paragraph styling and has outline, crop-mask and stacking limits. Those existing converters need their own native review before delivery; PowerPoint candidates must not be assumed portable to them.
- Native review used licensed Mac PowerPoint 16.113.3. The exact final ten-slide Google pilot and five-frame Figma pilot were opened, exported at 1920 × 1080, and compared slide by slide against source references. Render manifests record the exact PPTX hashes. The Google editor was the agreed visual reference where its wrapping differed from Google's SVG export.
- Native editability checks passed for representative text, vector shapes and pictures. Figma's gradient remained a native shape. All three selected Google GIFs showed motion in the final file's slideshow. Test edits were undone.
- Source font names were retained by user choice, with specified matches unverified: Google Comfortaa Light and DM Sans Light/Medium; Figma Inter Tight Regular, DM Sans optical size, and OpenAI Sans spacing. Native review does not turn these accepted exceptions into verified font matches.
- Two Figma image filters failed editable native reconstruction. Only those filtered pictures were flattened after individual user approvals; text and other artwork remained separate. The Google visual pilot omitted five hyperlinks with explicit approval. These choices apply to those pilots only.
- Source assets, output decks, comparisons and detailed decision records stay in the ignored local work folder. They are not included in the downloadable skills or this repository.

Windows native export is supplied but has not been tested live. The preview skills require source inspection, user choices and a fresh native review for each conversion, and require approval before extending a pilot to the remaining source slides or frames.
